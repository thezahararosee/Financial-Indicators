# Custom TradingView Indicators
Technical indicators that measure the Volume Weighted Average Price, Exponential Moving Average, and Standard Deviation of financial markets built on TradingView.

## Indicators

### VWAP+EMA 
An indicator that combines Volume Weighted Average Price (VWAP) with Exponential Moving Average (EMA).

* **TradingView Link:** [VWAP+EMA](https://www.tradingview.com/script/5p6HwXsZ-VWAP-EMA/)

### True Standard Deviation (STDV)
Measures real-time statistical volatility and price without sample bias.

* **TradingView Link:** [True STDV](https://www.tradingview.com/script/W0QGaINX-True-STDV/)
